# Agentic AI 益智遊戲教學平台

研究計畫「基於 Agentic AI 的益智遊戲教學平台：設計與學習成效評估」的實作。

在這個網站上，你可以和 AI 下五子棋、圍棋、中國象棋、國際象棋，或打德州撲克。

- **AI 會說明自己的想法**：它先用遊戲引擎查證，再決定怎麼下；查了什麼、查到什麼，就是它的思路，你可以一步步看。
- **每句說明都標出根據**：是依規則確認、算到底確認、電腦估計，還是依假設計算，不會把估計說成一定。
- **下完可以復盤**：AI 教練列出這盤的關鍵時刻、小失誤和建議下法，也可以直接打字問它「這步為什麼不好」。
- **對局會自動存檔**，隨時回來繼續下或重看。

## 在自己的電腦上試玩（Windows）

1. 下載專案：按這個頁面上方的 **Code › Download ZIP** 後解壓縮，或用 Git 下載：

   ```bash
   git clone https://github.com/FZR0/agentic-game-platform.git
   ```

2. 這台電腦要有 SQL Server（Express 或 LocalDB 都可以）和 ODBC Driver 18 或 17。
3. 在專案資料夾雙擊 `啟動遊戲平台.bat`。第一次會準備 Python 環境、設定資料庫，並詢問要不要從官方網站下載遊戲引擎（KataGo、Pikafish、Stockfish）。
4. AI 由 [Ollama](https://ollama.com) 上的語言模型擔任。第一次啟動時輸入你的 Ollama 伺服器位址，或在這台電腦安裝 Ollama 後直接按 Enter。連不上 Ollama 時一樣可以下棋，AI 改由遊戲引擎直接下。

準備好之後瀏覽器會自動打開首頁。
